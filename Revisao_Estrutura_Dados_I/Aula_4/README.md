Estruturas de Dados Práticas: Pilhas e Filas
Este projeto reúne três implementações que demonstram o uso de estruturas de dados para resolver problemas do mundo real.

📌 Conteúdo do Código
Exercício 1: Editor de Texto (Pilha - LIFO)

Conceito: Last-In, First-Out (Último a entrar, primeiro a sair).

Descrição: Gerencia o histórico de ações do usuário para permitir a funcionalidade de "Desfazer" (Ctrl + Z).

Exercício 2: Spooler de Impressora (Fila - FIFO)

Conceito: First-In, First-Out (Primeiro a entrar, primeiro a sair).

Descrição: Organiza chamadas de impressão garantindo que os documentos sejam impressos na ordem em que foram solicitados.

Desafio Master: Fila de Atendimento Médico (Deque)

Conceito: Fila de duas pontas (Double-ended queue).

Descrição: Menu interativo para gerenciar uma fila hospitalar, permitindo inserção comum no final da fila (append) e inserção prioritária no início (appendleft).

🛠️ Requisitos e Execução
Linguagem: Python 3.x

Dependências: Nenhuma externa (utiliza o módulo nativo collections).
